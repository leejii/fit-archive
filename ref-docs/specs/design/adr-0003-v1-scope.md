# ADR-0003 · V1 범위: 수동 입력 코어 우선

## 맥락
- "AI가 링크·사진에서 자동 추출"은 매력적이나, 쇼핑몰별 파싱은 취약하고 사진→사이즈 추출은 한계가 크다.
- 항상 **'돌아가는 앱'**을 유지하며 키우는 것이 목표.

## 결정
V1은 수동 입력 코어에 집중한다.
- 포함: 기록 생성/조회/수정/삭제, 검색·필터, 사진 첨부, **데이터 내보내기(기능)**.
- 제외(→ V2): AI 보조 입력(링크·사진 자동 추출).

## 근거
- 안정적으로 완성 가능한 핵심 가치(사이즈 이력 참조)를 먼저 확보한다.
- AI는 **"초안 제시, 사람이 최종 확정"** 원칙의 보조 수단 → 코어 위에 얹어야 안전하다.

## 원칙
- **얇은 수직 슬라이스**로 진행: '옷 한 벌 입력 → 목록 확인'을 가장 먼저 동작시킨다.

## 영향
- 데이터 모델은 수동 입력 기준으로 먼저 설계한다.
- V2에서 AI 파싱 결과를 이 모델에 매핑하고, 사용자 확정 UI를 추가한다.
