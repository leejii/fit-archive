# ADR-0001 · 플랫폼: 반응형 웹앱(PWA)

## 맥락
- 사용 시나리오: 쇼핑 중 폰으로 과거 사이즈를 참조하고, 나중에 PC로 기록을 정리한다.
- 사진 첨부·촬영이 잦고, 여러 기기에서 같은 데이터에 접근해야 한다.
- 개인 프로젝트 · 장기 유지 · **유지보수 쉬운 구조** 지향.

## 결정
반응형 웹앱으로 만들고 PWA로 설치 가능하게 한다. 단일 코드베이스로 폰·PC 브라우저를 모두 커버한다.

## 근거
- 코드베이스 하나로 폰·PC를 모두 커버 → 유지보수 부담 최소.
- 카메라·사진 첨부를 웹 표준 API로 처리 가능.
- 배포가 단순(정적/서버리스)하고 학습 자료·생태계가 두텁다.

## 고려했으나 보류
- **네이티브 모바일 앱**: 카메라 UX는 최상이나 빌드·스토어·유지보수 비용이 큼 → 필요 시 추후 재검토.
- **데스크톱 / CLI**: 쇼핑 중 폰으로 참조하는 핵심 시나리오에 부적합.

## 영향
- 프레임워크로 Next.js를 선정한다(스택 상세는 CLAUDE.md PROJECT 참조).
- 데이터가 기기 간 동기화되어야 함 → `adr-0002-data-storage`로 이어진다.
